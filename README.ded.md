# FastPrompter

**Клавиатурный, локальный черновик-воркбенч для Windows.**

Один глобальный хоткей открывает то же локальное рабочее место — заметки,
промпты, команды, сниппеты, проектные черновики и небольшие файловые наборы.
Ни браузера, ни облака, ни аккаунта.
