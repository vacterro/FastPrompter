# FastPrompter

**Klaviatuuripõhine, kohalik kriimuts- ja promptitöölaud Windowsile.**

Üks globaalne kiirklahv avab sama kohaliku töölaua — märkmed, promptid, käsud,
lõigud, projekti kriimuts- ja väiksemad failikomplektid. Brauserit, pilve ega
kontot pole vaja.
