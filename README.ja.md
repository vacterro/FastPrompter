# FastPrompter

**Windows用キーボードファーストのローカル・スクラッチパッド＆プロンプト作業台。**

一つのグローバルホットキーで同じローカル作業台を開く — メモ、プロンプト、
コマンド、スニペット、プロジェクトのスクラッチパッド、小さなファイル一式。
ブラウザもクラウドもアカウントも不要。
