## Группы категорий

### Глобальные: вызов, pie-меню, аварийный выход
**Alt+X** — переключение окна под курсором. **Shift+Alt+X** — радиальное pie-меню (темы, масштаб, инструменты). **Ctrl+Alt+Shift+Q** — убить процесс.

### Управление окном
**Ctrl+D** — 3 стадии: Zen (только минимальный редактор) → Solo (свернуть все остальные окна) → обратно к обычному. **Ctrl+Q** — цикл по 7 зонам привязки, пикеру FancyZone и пользовательским пресетам. **Alt+S/E/D/A** — блокировка геометрии, поверх всех, показать сайдбар, переключатель скрытия при потере фокуса.

### Очередь Watcher
**Alt+C** — поставить строку под кареткой в очередь. Привязана к блоку, переживает правки выше. **Alt+Shift+C** — Queue Master: просмотр/переупорядочивание/очистка очередей по всем silo.

### Markdown-форматирование
Все шорткаты форматирования переключают инлайн-маркеры: **Ctrl+B** → `**bold**`, Ctrl+I → `*italic*`, Ctrl+U → `<u>underline</u>`, Ctrl+T → `~~strike~~`, Ctrl+Shift+Q → `> quote`.

**Ctrl+W** вставляет разделитель `---` + умный сплит строки. **Alt+W** вставляет разделитель вверх + буллет над курсором. Оба настраиваются через Настройки → Разделители.

**Ctrl+Клик по буллету** циклит `-` / `•`. **Ctrl+Return** переключает `- [ ]` / `- [x]`.

**Ctrl+E** — форматирует текущую строку как заголовок. Настраивается: тип правила, буллет, метка времени, выравнивание. Откройте Настройки → Разделители и заголовки для кастомизации.

**Ctrl+СредняяКнопка** — удалить строку целиком с умным рефлоу: нумерованные списки перенумеровываются, маркированные закрывают пробел. **Alt+СредняяКнопка** — превратить каждую выделенную строку в буллет. **СредняяКнопка** — цикл состояния строки: обычная → отмеченная+зачёркнутая → неотмеченная.

**Ctrl+Shift+перетаскивание** — захватите строку под указателем (или всё выделение) и переместите к индикатору сброса; жирный, чекбоксы и image-пилюли переживают перенос.

### Навигация по silo
**Ctrl+1** до **Ctrl+0** — переход к silo 1-10. **Alt+↑↓** — последовательный обход. **Ctrl+N** добавляет пустой silo внизу.

### Макросы сниппетов
**F1-F10** вставляют предварительно настроенные текстовые шаблоны. Привязка содержимого через Snippet Manager (**Ctrl+S**) или правый клик по F-кнопке.

### Очистка + таймеры
**Ctrl+Shift+C** — очистить текст текущего silo. **Ctrl+Shift+T** — диалог таймера. **Alt+Shift+T** — поиск по хэштегам.

### Kanban и таблицы (T-630)
Внутри kanban-silo: **Alt+стрелки** двигают карточки. Внутри table-silo: **Tab/Shift+Tab** обход ячеек, **Enter** добавляет строку.

### Независимость от раскладки
Все шорткаты используют физические VK-коды через `HotkeyFilter` + `layout_shortcuts.py`. Работает независимо от активной раскладки клавиатуры. Привязка по позиции клавиши, а не по символу.
