# バカでもわかる FastPrompter（じいちゃんが説明する）

> 座れ、茶でも飲め。話は短い。余計なことは言わん。

## これは何だ

ワンホットキーのメモ帳だ。`Alt+X` を押すとカーソルのところに窓が出る。
`Esc` を押せば消える。カッコウ時計みたいなもんだが、役に立つ。中には：
番号付きの書きかけスロット（「サイロ」）が百個、`F1`–`F10` の用意された
スニペット、プロジェクトタブ、メモごとのファイル引き出し、アーカイブ、
ゴミ箱。ポータブルな Windows アプリだ — インストール不要、管理者権限不要。

## 何のためにある

メモ帳を探している間に考えを失くさないためだ。AI へのプロンプト、コードの
切れ端、買い物リスト、メールの下書き — 打ち込むと、窓は自分で隠れて、
テキストはもう保存されている。「保存」ボタンを押す必要はない：打つのを
やめた瞬間に、もうディスクに載っている。文の途中で電源が落ちても —
スロットは無事だ。

## なぜクラウドじゃないのか

書きかけのテキストはお前のもので、他人の知ったことじゃないからだ。
全部プログラムの隣の一つの `data/` フォルダに入っている：アカウントなし、
クラウドなし、テレメトリーなし。そのフォルダを USB メモリにコピーすれば —
それがバックアップであり、インストール全体でもある。一発でな。

## どこに何がある

- `data/local_data_v15.db` — データベース、リアルタイムに書き込まれる。
- `data/files/<プロジェクト>/<サイロ>/` — 各メモの添付ファイル、普通の
  フォルダだ。Explorer でいつでも開ける。
- `data/files/_trash/` — 中クリックしたサイロが行く場所：ここでは何も
  燃えない。いつでも釣り返せる。
- `Documents\.fastprompter\` — 全部の日次プレーンマークダウンミラー。
  万一アプリ自体が起動しなくても — テキストはどのエディタでも読める。

## 実際の使い方（短い版）

- `Alt+X` — どこからでも窓を呼ぶ／隠す。
- `F1`–`F10` / `Ctrl+Shift+1`–`9` — スニペット 1-10 を貼り付ける。
- `Ctrl+1`–`Ctrl+0` — サイロ 1-10 にジャンプ。
- `Ctrl+N` — 新しい空のサイロ；`Alt+Up`/`Alt+Down` — 間を歩く。
- `Ctrl+W` — 間隔付きの --- 区切りを挿入。
- `Alt+W` — 間隔付きの --- 区切りを挿入し、新しい箇条書きを始める。
- `Ctrl+E` — 行をヘッダーにする：# + 太字 + 下線 + タイムスタンプ。
- `Ctrl+Return` — [ ] チェックボックスを切り替え。
- `Ctrl+B` / `Ctrl+I` / `Ctrl+U` / `Ctrl+T` — 太字、斜体、下線、取り消し線。
- `Alt+Backspace` — 前の単語を削除。
- `Ctrl+S` — スニペットを保存。
- `Ctrl+D` — 禅モード。
- `Ctrl+Q` — 窓を角にスナップ。
- サイロを中クリック — ゴミ箱へ（完全には消えない）。
- サイロにマウスを乗せる — ボタンが出る：チェック ✅、ファイル 📁、ピン 📌、アーカイブ 📥。
- プロジェクトのドロップダウンを右クリック — タブの追加、名前変更、削除。

全機能リスト、スクリーンショット、各ボタンの説明は
[README.md](README.md) と [Wiki](https://github.com/vacterro/FastPrompter/wiki/User-Guide) にある。
このガイド自体がおじいちゃん口調の説明だ。

## 結論

ホットキー一つ — `Alt+X` — で、考え・コード・リンクのぐちゃぐちゃが
全部一か所に収まり、どこにも逃げず、誰にも報告しない。じいちゃんも
お墨付きだ。
