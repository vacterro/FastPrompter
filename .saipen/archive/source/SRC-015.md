----------------------------------------------------------------------
B1. CURRENT CODE EXPLAINS THE SYMPTOM
----------------------------------------------------------------------

Inspect:

    src/fastprompter/ui/snippet_panel.py
    DraggableSiloButton

Current hover flow:

    enterEvent()
        _hover_showing = True
        start single-shot 80ms timer

    timer
        -> _update_hover_buttons()

    _apply_tick_state()

----------------------------------------------------------------------
E1. SEPARATE RUNTIME STATE FROM STARTUP PREFERENCE
----------------------------------------------------------------------

Current AmbienceController already contains TWO concepts:

RUNTIME STATE:
    stopped / running / paused

PERSISTED WISH:
    AmbienceStore.runtime_enabled()

They are deliberately not the same.

Expose this distinction explicitly.

Recommended UI:

TRANSPORT:
    Start
    Pause / Resume
    Stop

SEPARATE CHECKBOX:
    Start ambience with FastPrompter
    or equivalent concise wording.

Do not overload the Start/Stop transport control with persistence semantics.

----------------------------------------------------------------------
E2. EXACT TRANSPORT CONTRACT
----------------------------------------------------------------------

STOPPED:

    Start      enabled
    Pause      disabled
    Stop       disabled

RUNNING:

    Start      disabled
    Pause      enabled, label "Pause"
    Stop       enabled

PAUSED:

    Start      disabled
    Pause      enabled, label "Resume"
    Stop       enabled

Start:

- starts the CURRENT saved rule set;
- runtime -> RUNNING;
- does not silently change startup preference unless that control explicitly
  owns that preference.

Pause:

- holds current ambience runtime;
- runtime -> PAUSED;
- does not change startup preference.

Resume:

- resumes paused runtime;
- runtime -> RUNNING;
- no stale old state resurrection beyond current saved rules.

Stop:

- physically stops current ambience;
- runtime -> STOPPED;
- startup preference remains whatever the separate startup checkbox says.

The state label must be explicit:

    STOPPED
    RUNNING · N active
    PAUSED · N held

No interpretation required.
